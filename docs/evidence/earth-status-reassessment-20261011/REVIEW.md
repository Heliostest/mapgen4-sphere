## 已核对且成立的关键边界

- **正式/实验分开**：正式默认采用光照、观测冰库存/三热库、内流参考树与有限湖盆。共享水汽默认关闭，classic 默认；balanced/high 的局部状态和守恒机制通过并不等于区域气候、雪线或流畅播放通过。主报告没有将“五部分代码存在”写成“五部分全部正式启用”。
- **NSIDC 与统计域**：主报告同时列全半球与 ≥60°N/≤50°S 历史 cap，避免裁掉异常低纬冰。`capOverlap` 是按等面积格的正弦纬度重叠计算，不是把整个边界父格粗略划入 cap。1981–2010 极值、15% extent 与厚度转换代理明确分开；主报告没有用该旧年代正常值声称 2026 年观测，也没有给出伪精确卫星百分比误差。
- **GPCC 异格正常值**：模型列是存档解析参考年 P，右列是不同最近观测格的 1991–2020 正常值。南麓/印度/北澳/东坡目标坐标与模型探针不完全一致，主报告明示筛查用途、格心及插值不确定性；没有用一天雨率乘 365，也没有把阿塔卡马内陆粗格当极旱海岸观测。
- **两天实验与全年初始化**：四组合保留同正式库存和热状态，变更 transport 与辐射分配，研究的是播放算子短期响应。报告明确不代表正常 UI 重建 transport 初态或全年季风验收；印度两天 0 雨、北澳两天有雨、澳内陆两天 0 雨都没有被写成全年结论。旧全年数值标为历史实验，当前初始化闭合未改与当前全部年度演化重新复现分开。
- **温度与冰雪**：父空气、classic 当地估计空气、陆/海表面和精细局部热库有不同定义，报告不将大温差当作同一种观测气温误差。当地冰厚与粗格库存分母、SWE 与冰厚、年参考与最新步通量分开；ETOPO 冰面 DEM 不再次叠加 GFZ 厚度。导入山地冰厚为 0 未被解释为现实无冰川。
- **守恒与性能**：预算检查使用独立补偿求和，但依赖模型初始账与净辐射计数，不能验证外部强迫拟真；主报告已有这个限制。Node 步成本与浏览器回调没有冒充 FPS，节流/前台不确定性已记录。high 只有 24 天资料，没有被授予全年或流畅验收。
- **湖盆**：树内部终止、有限库存/蒸发/鞍部出流是机制证据；未导入现代湖水位、库容、人工调控和独立淡水湖冰。采样 checkpoint 无出流不证明整年没有任何溢流，主报告使用“采样时点”表达正确。

## 图证支持程度与建议

`formal-polar-contact.jpg` 的四列来自 day0/day24/day180/day365。可见北方陆雪退去、格陵兰内陆白色保留、南极外围近圆形宽冰圈及有限季节变化，支持“库存修复生效、海冰仍不可信”的描述。白色是复合地表显示，厚度和种类必须依靠库存数据判定，不能从图直接计面积或说所有白色均为海冰。

`refinement-day24-contact.jpg` 的三列视角一致，balanced/high 的直角或块状雪界清楚；支持“更多持久局部状态没有普遍更自然”。图不能证明现实雪线高度或迎背风降雨已改善；这些结论须由同月高程带和水量统计检验，主报告已保留此边界。

另有两处可进一步明确，但不影响发布结论：

1. `MODEL-AUDIT.md` 将 day270 称为“相反季节”；其实际接近北冬至/南夏至，而 day365 接近春分及北冬末。建议写出近似季相，避免读者把 day270 当北冬末；主报告与拼图 day365 标签已有基本说明。

优先顺序“统一诊断→水汽时间收敛/海到陆供水；独立海冰循环；性能与雪片界”与证据相符。P0/P1 的验收方向已具体，但正式启用前仍应预先给同面积区域误差、时间收敛、重复年漂移和固定硬件长任务/加载时间的数值阈值；当前文件已把它们标为下一步项目验收，未冒称已经达到。
