# SpeedyWeather T32 / 8 层独立试验

用户已选定此前提出的独立计算进程、T32、8 层湿大气试验，要求真实积分、预算、GPCC/NSIDC 对照，之后接入现有地球界面。此目录与 build/earth-speedyweather 是实验区；正式 earth-simulation.json 与 DEFAULT_* 不改，不将外部气候结果写入旧模型的物理库存。

## 固定设置

- Windows x64 官方便携 Julia 1.12.7，下载字节按官方 versions.json 的 SHA256 校验，放在 build 内，不改系统 PATH。
- SpeedyWeather 0.23.0 注册版本，独立 Project/Manifest 与 depot；CPU、Float64、官方 T32（该版本的一基 API 为 truncation=32，包含常数项，最高球谐次数 31）、8 个大气层、固定随机种子。
- PrimitiveWetModel，Earth 地形与陆海掩膜；交互式 SlabOcean（50 m）、ThermodynamicSeaIce、默认两层 LandModel。海温气候态仅作初值，统计阶段不使用规定季节海温/海冰来伪装预测。
- 先运行短期探针确认 API、量纲、输出与诊断时序；正式积分从 2001-01-01 开始，预热至 2006-01-01，统计 2006 的完整非闰年。所有时间来自实际求解器时钟，不用温度/水汽重设或日历标签代替积分。
- 保存原生初值和统计期起止存档，记录软件、输入资产、脚本、数据和运行配置哈希；验证存档续算。试验不代表多年平衡气候态，也不等同于旧单层模型同库存对照。

## 预算与验收口径

直接从实际时间步诊断与预报库存取数。空气质量以本模型表面气压/重力与高斯面积权重计算；大气水柱以各层实际比湿、sigma 厚度和表面气压积分，检查储量变化与蒸发减总降水。陆地水按实际土壤水、雪、蒸发、降水和径流检查。海洋热按混合层热容、实际海温变化、短长波及显/潜热通量检查；记录冻结温度钳位的能量调整，不能把它当成已实现的有限海冰潜热库。

同时输出 TOA 净辐射及可计算的热库存漂移。标准大气模型的耗散、湿度裁剪、分裂积分、海冰浓度调整等残差均公开，不用全局补偿掩盖失败。海洋不是有限水库存、海冰没有厚度/质量；不能声称整个地球水库存或含海冰潜热的总焓严格闭合。

预先记录空气质量相对漂移 1e-6、大气水残差 max(0.05 mm, 年蒸发/降水总通量的 0.1%) 的初步检查阈值；超出则记为失败并排查，不在看到结果后放宽。陆海预算先按实际积分格式列出闭合量和未解析量，未知项不标为通过。

GPCC 沿用 v2022 1991–2020 原区域与共有效支持；NSIDC 沿用 G02202 v2 1981–2010 原固定海域支持及 15% 范围阈值。外部模型使用实际海冰浓度，不套用旧模型的 0.5 m 浓度转换。保存 native 网格面积统计；与旧报告对照时，将量映射到已有 48×24 等面积验收网格并检查总量与支持。降水含雨雪，累积量/率明确区分；月度按实际公历积分。

重点列出印度、喜马拉雅山前、西藏、温带四区、北澳/西南澳、热带；年量和季节分配都要公开。低分辨率无法解析狭窄山脉，不以高分辨率地形显示冒充相同气候分辨率。

## 界面边界

验收后提供独立、只读的外部气候回放页，复用现有地球地形与绘制器，选择实际积分时刻/统计月份、大气层和风/温度/气压。明确区分瞬时与月平均数据。回放不推进旧水热求解器、不改库存、不改正式默认。截图验证真正 WebGL 风向与场的显示，不代替数值验收。
