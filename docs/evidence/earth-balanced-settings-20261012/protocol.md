# 三项约束的数值对照（2026-10-12）

正式 Earth 存档和 DEFAULT 配置保持不变。候选仅改变独立存档中的全局数值系数，不采用观测区域掩膜、加水、重生成气候、温度修正、结冰温度或显示阈值调整。

主要对照是上一轮发射率 0.575、热输送 0.80 的独立融冰档；发射率 0.595 的温和档作为更严格的澳洲防退化参考。此前完成的相同输入年度积分可以复用，并保留路径与哈希。每个后端内部的所有试验须有相同初始库存 SHA256；不同路由后端的数值不能互相冒充。

粗路由筛选采用原正式存档相同水、气温、陆温、海温、显热、焓、时间和风的初始状态，不初始化新气候。完整验收从同一 lake-day0 存档开始，保留里海有限库存及所有地形路由库存。初始库存哈希包含全部有限水库、温度、显热、焓与地形水量。改变热容量或混合层深度的设置不纳入本轮，以免改变初始热库存。

目标判定在完整地形年度积分上进行：

- 两半球同网格 NSIDC 月海冰范围 MAE 均小于 0.575 对照；实际年末海冰质量也必须降低。
- 欧洲、北美东部、东亚、西西伯利亚四区的等权 GPCC 年降水绝对偏差均值，须小于两档对照。
- 澳洲西南和北部的 GPCC 年降水绝对偏差，分别不得高于 0.595 温和档；不能用两区平均互相抵消。
- 所有已使用的 GPCC 区域完整公开，单区退化不得用温带平均掩盖。三项目标通过不等于全球气候验收通过。

观测沿用 GPCC v2022 1991–2020 normals 和 G02202 v2 NASA Team 1981–2010 月浓度缓存，使用既有陆地/海域共同有效支持。NSIDC 15% 范围阈值与模型质量/0.5 m 的覆盖诊断固定不变。存档冰量和实际积分降水是证据，颜色截图仅检查形态。

每个新完整积分至少每日检查一次总水、焓、逐格水汽通量账本、地形水分区闭合；最大残差阈值分别为 5e-6 mm、0.005 J/m²、1e-8 mm、1 m³。每个试验都必须严格恢复存档并得到完全相同的下一步快照。最终候选另做 900 s 粗路由步长对照，明确不冒充完整地形的 900 s 年度积分。

只评估一个瞬态物理轨道年，不把它称为长期收敛气候或全面观测校准。

## 累加精度修复后的最终对照

两个 900 s 复核的旧式累加触发严格恢复检查，故先修复浮点累加精度，再重新积分两个候选与两个参照。最终四个完整积分都启用 compensatedOceanTransfers；它只保存舍入补偿，既不放宽预算/存档阈值，也不调整库存来消除残差。最终参照不复用旧算法积分。正式 DEFAULT 不含此开关，旧存档与默认行为保持。失败记录及修复前筛选仍保存并明确区分；最终步长复核使用修复后的相同算法。
