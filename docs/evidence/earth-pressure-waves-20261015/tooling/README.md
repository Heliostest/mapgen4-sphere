actual seal.mjs prefix before review binding and all file creation; the
generated module validates existing numerical/project/derived evidence.

while still hashing every internal/external binding. preseal-v2 passes all
284selected assertions and nine ancestor manifests. Both original/generated
scripts, output logs and source hash records are retained; their relative
imports assume their original build/c11-integration execution location.
