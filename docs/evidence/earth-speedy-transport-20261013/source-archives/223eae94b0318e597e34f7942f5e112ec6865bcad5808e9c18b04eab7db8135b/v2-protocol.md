# 第二批确定性修复的隔离检验

第一批五个一年分支已完成且季风未通过，两组六年候选仍保持源码冻结。后续检查发现新的明确实现疑点；它们必须有独立原生 RED、修复 GREEN 和机制证据才能接入第二批模型，不能以降水目标倒推参数。

候选范围：

- 半隐式温度背景垂直平流及其线性算子：必须成对一致，有限差分验证原生完整温度核与拆分后算子。不得用湿度补偿源伪装修复。
- 陆面湿度通量：保留正蒸发算法，禁止以土壤可用指数制造暖面未饱和凝结，保留 q 大于地表饱和值时的真实露水。
- 灰体长波地表反射：保留发射率参数和原光学厚度，仅补 Kirchhoff 一致的反射边界；黑体极限必须与原生逐值相同。此修复不会被当作抵消短波云冷却的调参。

计划使用新的 `transport-v2-model.jl` 和 `run-v2.jl`，原有运行文件一律不修改。先做三天两模式物理预算及新组件测试，随后从相同冻结 2006 状态做分项响应，并从冻结 2001 初态做 `all-corrections-seasonal` 连续六年积分。第二批仍沿用原分辨率、时间步、初态、海温、区域支持与验收门槛；没有新的地方性降水校正、阈值放宽或观测回写。

本文件描述检验约束，不声明任何未完成实验通过。最终报告必须同时保留第一批失败结果、第二批结果及尚未解决的模式适用性限制。默认长波对水汽和云无反馈是当前理想化配置的已知限制，不能仅凭此认定新编码错误或擅自添加未经验证的云光学参数。
