# 第三批附加热力分支选择

在 `split-reference-sensitivity` 完成后，增加 `thermal-split-reference-sensitivity`，使用已冻结的 V3 入口及其现有 `PHYSICS_FIX=combined-implicit-split-reference` 开关。

选择原因：全部修复的一年结果中，印度与北澳均通过季风四项中的三项，但不能把这一响应单独归因于隐式参考。它同时含背景温度输送、露水条件和长波反射修复。先前 V2 的热力单独分支会失稳，未产生完整年度结果，因此缺少可比较的稳定热力分支。

新分支保留气块与云修复，并加背景温度输送及分离隐式参考；露水和灰体反射继续使用旧实现。它仅作为机制对照，不是推荐保留已知错误。不会重新选择参考温度、时间步或任何物理参数，也不依据区域雨量改参数。

继续使用原冻结 2006 初态、原干质量目标、两个原生时间层、T32、8层、30分钟、规定海温与既定支持/门槛。原辅助行保留。输出标签不同，所有运行中的 V3 source/protocol/driver 保持不动；这份补充选择记录独立保存。已开始的全部修复六年积分继续，不另开热力六年积分。
