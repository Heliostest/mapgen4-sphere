# 共享压力—水汽核心 C1：实现与守恒通过，物理精度未全部通过

本轮把上一轮独立的水汽“影子库存”推进成了可运行的共享压力／质量／水汽子系统。压力、持久动量、水汽使用同一批局部质量转移；原始 2001 状态在原 3168 格、8 层 Gaussian 面积上完成三天无源验证。空气、水和干空气收支闭合，湿度非负，常量湿度保持，续算逐位一致。

**这是有限子系统的实现与守恒验收。粗步长压力精度、极区局部空间精度、完整原始方程耦合和气候验收仍为 false。** C1 尚不能替换正式模拟核心，也没有产生新的六年气候结论。

## 实现了什么

- `conservative-core.jl`：压力／持续动量的 backward Euler 隐式耦合、sigma 层间质量再分配、同一共享通量的隐式上风水汽推进、原子拒绝与明确缩步、完整自身状态 checkpoint。
- `conservative-grid.jl`：保留原 Gaussian cell ordering 和 `A=4πw`；9352 个几何通量采样位置，面积不重新归一化。
- `mimetic-gradient.jl`：相同经度重构梯度 D，用配对的 `D' H/R` 质量散度，保持变分能量结构；27330 条展开的邻域质量转移用于水汽。这些转移并非全部是原几何网格的物理面。
- 湿／干两种库存由同一矩阵求解，每格用较小组分表示，修复 q=0、q=1 和混合边界的舍入失效；没有剪裁、总量缩放、残差注入或温度下限。线性求解最多一次迭代改进用于本轮原生案例。
- 运行记录保留确切源码归档、前后输入哈希、退出码、日志和失败尝试。最终运行覆盖原始初值、6 个 NetCDF 边界资产、105 个安装的原生源码文件和 Julia 锁定环境。

压力步进保持 j 为独立持久自由度。它不是丢弃旧 j 的椭圆扩散，也不是原有八层温度／散度／log-pressure 半隐式求解器。固定等温地形参考取 `pref=1e5*exp(-g*h/c²)`，`c²=R_dry*288 K`。重构后的任意网格不保证压力矩阵都是 M-matrix；正预测量和实际正压力都必须通过检查。达到最小步长仍失败会明确停止。

## 原始八层状态：三天无源结果

从冻结的原始 2001 初值导入，沿用已单独验证的 scalar 辅助模态投影。导入本身改变空气约 `+5.52117e-5 kg/m²`、水约 `-1.75780e-6 mm`，独立列在导入账本，未冒充 E−P 或推进误差。投影后的共同初始水库存约 `45.42158602492369 mm`。

| 步长 | 水汽场 | 接受步数 | 拒绝／缩步 | 三天水量漂移 mm | 三天空气漂移 kg/m² | 续算 |
| ---: | --- | ---: | ---: | ---: | ---: | --- |
| 1800 s | 原始湿度 | 144 | 0 | −7.1054e−15 | 0 | 逐位一致 |
| 1800 s | 常量 0.012 | 144 | 0 | −5.6843e−14 | 0 | 逐位一致 |
| 1800 s | 0／0.02 尖锐边界 | 144 | 0 | −1.4211e−14 | 0 | 逐位一致 |
| 900 s | 原始湿度 | 288 | 0 | −7.8870e−13 | 0 | 逐位一致 |
| 450 s | 原始湿度 | 576 | 0 | −1.3500e−12 | 0 | 逐位一致 |

常量湿度最大绝对误差 `7.7525e−15`；尖锐边界湿度始终非负，上界最大舍入超量约 `1.75e−15`。三种水汽场的压力和 j 轨迹最终逐位相同，说明湿度场没有通过拒绝／缩步改变压力路径。原生模型状态只用于导入和只读谱投影诊断，其库存 hash 未被核心回写修改。

按每个格子自身质量归一化，所有案例最大局部空气残差约 `1.61e−13`、水残差 `3.82e−17`、干空气残差 `1.61e−13`，均通过预定 `5e−12` 门槛。底部 sigma 闭合最大绝对残差约 `2.00e−12 Pa sr`。这些局部检查与全局库存检查独立。

原生案例从倒数第三步的 checkpoint 继续两步，结果逐位相同；独立小网格检查还使用重新构建、空 factor cache 的核心恢复，后续七步逐位一致。这里只保证当前版本自身状态的续算，不声称能无损导入任意旧 LF/RAW 历史。

## 时间精度：保留失败，并用独立精确解定位

最初的邻步长差异门未通过：1800→900 s 最终压力 RMS 差是 `11.7832 Pa`，900→450 s 却为 `16.6781 Pa`，比值 `0.7065`。`candidate-c1-analysis` 的退出码 1 和原始失败日志保留。这一门没有被改写成通过。

随后直接对同一个固定空间压力系统的 3168 个模态求解，用连续时间 sin/cos 解及精确 backward Euler 放大因子作独立对照。它验证时间推进，不验证球面连续方程的空间准确性，也不验证水汽的精确时间解。

| 步长 | 实际压力对精确 BE 解 RMS 差 Pa | 动量／pref 对精确 BE 解 RMS 差 m/s | 对连续时间空间系统的压力 RMS 误差 Pa | 最大压力误差 Pa |
| ---: | ---: | ---: | ---: | ---: |
| 1800 s | 4.05e−11 | 2.36e−12 | 163.842 | 616.322 |
| 900 s | 4.27e−11 | 2.35e−12 | 160.067 | 601.226 |
| 450 s | 5.06e−11 | 2.35e−12 | 151.205 | 560.796 |

这确认了 C1 对既定 BE 方程的实现，且真时间误差随细化下降；并不证明 30 分钟精度合格或三个步长已处于一阶渐近收敛区。最大 `ωΔt` 分别为 `11.71 / 5.86 / 2.93`。只做模态解析计算、把步长降至 `14.0625 s` 后，三天压力 RMS 误差仍约 `43.64 Pa`。总动量能量包含不传播的分量，不能用其接近保持来掩盖压力波误差。

## 空间精度：弱传播改善，极区强误差保留

原始非匹配纬圈 TPFA 对 x/y 球谐的 Laplacian 相对误差为 `31.3%`。仅做同经度重构会产生非对称算子和复数声学模态；简单对称化也未通过局部细化。两个候选的诊断均保留。

选用的变分方案满足能量恒等式，并在完整压力／持续动量／水汽核心中通过波传播细化：12/24/48/96 纬圈、每周期 512 步，对解析 BE 球谐时间因子的最大相对压力误差依次为 `0.013388 / 0.003430 / 0.001053 / 0.000505`。独立方案复核扩展到 192 纬圈、倾斜 l=1、l=2，以及 4096 步，保留改善趋势。

但是强 Laplacian 的 x 相对误差在原网格仍为 `0.0827385`，极区局部误差随细化不降。它通过的是有限的弱解／波传播验证，完整空间精度标志仍为 false。

倾斜刚体旋转在 12/24/48/96 纬圈的水汽相对 L2 误差为 `0.6332 / 0.4246 / 0.2585 / 0.1468`。此测试使用几何面上解析积分的无散质量通量，独立于原始风的低阶采样接口。上风输送保持界限与库存，但扩散明显。

## 仍不能直接接回的接口

对三天结果做只读谱投影，尖锐湿度出现 `−0.00210658` 的负值；若再剪裁会添加约 `0.194286 mm` 水。真实湿度投影也出现约 `−2.96e−5` 的局部负值。因此投影的 q/logp 不能取代权威网格库存。

后续必须解决粗步长耗散／相位精度、极区离散、非线性动量／科氏力、斜压温度与原半隐式耦合、E−P 与物理过程的共享质量约定、扩散和历史状态接口。上一轮印度／北澳降水和 TOA 偏差未在本轮得到新的完整气候检验。
