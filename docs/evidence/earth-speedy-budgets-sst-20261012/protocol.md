# SpeedyWeather 排水、空气质量与规定季节海温对照

用户已授权修土壤排水记账与空气质量漂移，并以同初始大气和陆地库存做规定季节海温对照。全部新增文件位于本实验目录与 build/earth-speedy-budgets-sst。旧实验、Julia 包源、正式地球场景与 DEFAULT_* 不改。

## 固定试验

Julia 1.12.7 / SpeedyWeather 0.23.0 / CPU Float64 / truncation=32 / 8 层 / 3168 Gaussian 点 / 1800 s，原生两次 900 s 启动。输入使用上一轮 annual-initial.jld2 在第一次物理推进之前保存的真实状态。逐项哈希并断言三组的大气光谱状态、物理温湿风压、陆地土壤/雪一致；每组独立运行，禁止时钟跳跃、气温/湿度/土壤重设或区域雨量修正。

从 2001-01-01 连续到 2007-01-01，五年预热、完整 2006 年统计。原配置 reference 为上一轮已冻结真实积分，需复核其输入初始状态哈希；新组为 corrected-slab 与 corrected-seasonal-sst。新组相同质量/排水修复、相同初始大气与陆地库存、相同地形/辐射/凝结/对流/海冰配置；只更换 SST 边界。

## 修复与口径

- 土壤下层超额移除计为 deep drainage（m 累计），负土壤水裁剪增加的水也独立记录。只补诊断，土壤演化及原 upper runoff 必须与原生 bucket 逐值一致。陆地水检查包含 soil+snow、雨雪、陆地蒸发、upper runoff、deep drainage、土壤裁剪水源和正积雪上限移除；仍展示未补排水的原始残差。原生雪模块把潜在融雪写入未裁剪 tendency、把实际可融雪通量传给土壤，负雪候选的裁剪抵消未实现融雪，并非物理新增水源；该量单独诊断而不重复计入物理预算。
- 湿大气 ps/g 是总气柱质量代理。W=Σ(q Δσ) ps/g，干空气质量为 ps/g−W。原生维持平均 log(ps) 不维持这两个面积积分。修复将压力的全局零阶自由度用初始干空气质量约束，空间压力梯度及温湿风不直接重设；两个 Leapfrog 光谱时间层均处理，实际格点当前层同步。**这是显式数值质量固定器，不宣称原动力核变成完全守恒有限体积格式。** 保存未约束候选干空气漂移、均压模式调整及对水和显热代理的影响；不给修正取物理蒸发或降水的名称，不隐藏残差。
- 所有组重算旧 ps/g 指标、干空气质量、总气柱质量变化与 E−P。总气柱质量随水汽交换变化是物理允许项，不能把它一律当作干空气泄漏；指标变更须明确展示，不改写旧验收。
- 规定 SST 使用同一固定包提供的 sea_surface_temperature.nc，读取元数据与 SHA，不假称其为本次新下载的同期观测。12 个月均场按真实公历的月中心连续线性插值（含 Dec→Jan 和闰年），不使用月初插值。源数据的冻点以下值按明确的海水冻点限制记录，陆地占位 SST=285 K。起始物理 SST 也从同一存档复制，后续外部边界才接管。两组都先运行相同原生 slab 表面热通量与海冰响应，规定海温组在每个完成步施加明确的外部温度边界；维持该边界所需的热量逐格记账，禁止把它算作封闭海洋守恒或跳过原有海冰冷却响应。
- 海冰参数化保持同一原生热力浓度模型，以免额外替换冰边界混淆 SST 对照。SST 引起的海冰反馈属于此边界配置的总效应，不能单独归因为洋流或单个湿过程。

## 验收

质量固定器的 waterCorrectionMm/sensibleCorrectionJm2 只记录当前物理层的即时库存改变。RAW 保留记忆层的 pressure mode 另列 memoryWaterModeMm、memoryTotalMassModeKgM2 与最大 delta；它不是额外发生一次的物理通量，不能重复扣入当前层水预算。未解释的后续动力/滤波影响仍保留在大气水残差中。

干空气质量每步相对误差≤1e-6（目标接近舍入量级），未约束候选值也公开。大气水原始残差与扣除已记录数值模式影响后的残差均列出，沿用 max(0.05 mm,0.001*(|E|+P)) 门槛。补齐出水后的陆地累计水残差≤1e-6 mm；任何其他裁剪源/未知项不得标成已闭合。

规定 SST 组将海洋显/潜/辐射通量列为外部能量交换，不能套用封闭 SlabOcean 热库存验收。两组都不具备完整有限海水/海冰潜热库存，本轮不声明 NSIDC 海冰预报通过。

GPCC 仍用 v2022 1991–2020、原 11 区、原固定有效陆地权重、48×24 保守映射。重点印度/北澳：年量、各月量、DJF/JJA、夏季（印度 JJA；北澳 DJF）份额、雨季峰值，以及区域低层风、湿度、整层水汽和海温梯度。保留其它温带、喜马拉雅、西藏、澳洲地区的回归结果；一次 SST 对照不自动证明某个过程为唯一原因。

保存启动源/输入哈希、模型状态、实际累计通量、每日日志、统计年单独账本和存档下一步一致性验证。至少短期证明没有质量修复时的真实漂移、修复后候选漂移依然被诊断。独立审查数值与显示链后才生成真实地球回放；新页面提供配置切换、月份、八层风/温，不启动旧求解器，不自动旋转地球。
