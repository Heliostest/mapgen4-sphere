# 本轮实现与验证口径

## 已确认的机制错误

1. `ImplicitCondensation` 的候选再蒸发量先全部从雨滴通量扣除，之后湿度增量还会经过隐式热力反馈和松弛时间缩小，二者不相等。本轮使用最终有符号湿度增量同时更新空气与雨滴，正湿度增量受可用液态雨量约束。冻结初态三天的原生大尺度过程漏水约 −0.177 mm；修复后该过程的倾向与降水相抵至舍入精度。六种单柱情形同时验证水和以液态水为基准的湿焓，其中有冻结、融雪、再蒸发、凝结与再蒸发共存及无凝结。
2. 旧干空气质量固定器只调整压力，从而连带改变每层水汽库存。本轮令 `p'=λp, q'=q/λ, λ=(D_target+W_raw)/M_raw`，保持每格每层 `p*q` 不变，只调整干空气质量。两个 Leapfrog 谱层均处理，当前物理格点同步；不把 RAW 记忆层当作第二次物理通量。压力空间梯度保持不变，显热代理变化仍独立记录。它仍是显式数值干质量固定器，不是重写为有限体积动力核。
3. 原生垂直扩散的两个邻居索引都等于当前层，导致所有梯度为零。仅改索引还会混淆高度扩散系数 m²/s 与 sigma 坐标。本轮从静力平衡变换为 `K_sigma=(g*sigma/(R_d*T_virtual))²*K_z`，用共享界面通量、sigma 层质量和隐式三对角求解实现有界的层间交换；无柱顶/底通量，不做水量裁剪。
4. 原生地表 Richardson 数用同一个最低气层温度构造地表和空气参考，始终非负，不读取真实地表状态。候选恢复独立地表虚温，同时修正垂直稳定性对地形高度基准的依赖。Frierson (2006) 式15的地表参考与式16的最低气层参考保持区分。原数值系数、空气外推、海冰/雪绝热保留，没有按印度或北澳雨量调参。详见 `monsoon-diagnosis.md`。

## 启动与预算

原三天门槛保持 `max(0.05 mm, 0.001*(|E|+P))`。单独修凝结尚余约 +0.071 mm，继续使用保水的干质量固定器后为 slab +0.0087594 mm、seasonal +0.0085790 mm。初始状态哈希仍为 `4c665c83b08918fad6f8b67968fae472539c8796515afc93a22099d682b44a68`。

这是三天终点通过，不代表所有子日时刻已严格闭合。完整逐步记录保留：修水后的第一次日内误差最大约 −0.197 mm（4.5 小时），不可用终点值隐去。仍存在 Leapfrog/谱动力与裁剪的离散误差，未强行加入全局湿度残差固定器。后续联合物理修复须另外检查三天与完整积分，不沿用此结果代替验收。

联合方案的独立逐过程审计已完成：三天残差 slab −0.00636857 mm、seasonal −0.00608276 mm；凝结、对流、垂直扩散与地表交换分别闭合至舍入误差。联合方案4.5小时的最差中间残差分别为 −0.21977751 mm、−0.22016438 mm，因此不能声称每一步通过原0.05 mm门槛。原始逐步结果见 `build/earth-speedy-moisture-monsoon/audit-coupled-mass-fixed.json`。

## 长积分配置

- `moisture-seasonal`：仅再蒸发守恒与保水干质量约束；保留原混合和地表稳定性，用于机制对照。
- `coupled-slab`：同时启用垂直混合与地表稳定性修复；自由 50 m 混合层海温。
- `coupled-seasonal`：同一联合修复；规定月中心插值的季节海温，外部热量独立记账。

三组从同一 2001-01-01 状态真实推进至 2007-01-01；T32、8 层、30 分钟，原生两个15分钟启动，五年预热后统计2006年。上一轮 seasonal 作为冻结基线。保留原 GPCC 有效陆地支持和其余九区回归，单年敏感性改善不能自动升级为经过气候验证的正式默认。

本轮预先定义的季风筛查：峰月距 GPCC 峰月不超过一个月、当地夏季降水占全年至少一半、年量偏差不超过25%、月降水MAE较上一轮下降。四项分别公开，不用总平均掩盖个别失败。

## 数据与限制

月均输出含各层温湿风、柱水与水汽输送、地表温度、陆海蒸发/显热、对流/大尺度降水、日照与净长短波，以及地表Ri/交换系数/混合发生率。湿度诊断使用每步相对湿度求平均，不以月均比湿除月均饱和湿度替代。部分新增过程诊断仅联合修复组具备，旧组不伪造缺失数据。

仍继承原模型没有独立海冰皮肤温度、没有有限厚度海冰水量/潜热库存等限制。没有声称完整海陆气水量或能量全部闭合。固定包源、旧实验、正式地球场景及 DEFAULT_* 保持不变。

独立审查进一步明确：混合系数仍保留原生基于边界层顶 Ri 的稳定抑制近似，不是 Frierson 全方案复现。检查点未序列化月累计 Observer，边界层组件由相同源码的 factory 重建；当前重启测试只证明同源码物理下一步逐位一致，不能用于跨版本恢复，也未证明六年统计可断点续跑。本轮长积分采用连续运行，不依赖该恢复功能。审查后仅给 boundary-layer.jl 补齐 EUPL 来源头，物理代码未改。
