# 东亚季风：形成机制与当前模型的结构核查

2026-10-15；核查基线 `6bbbad414f5602cf532e41adbcc6a46a5286b9b3`。本轮仅研究和代码核查，不改物理公式、参数或正式场景，不重复跑年度拟合。文献笔记见 [SOURCES.md](SOURCES.md)。

## 当前判断

**重要缺口已在代码中确认：运行中的模型没有分层大气环流，也没有随实际风输送大气显热的方程。它不能完整表达高空西风与青藏高原作用、下游上升运动、低层湿气流辐合及其季节迁移。** 这使“把单格对流调强”不足以解决东亚雨季问题成为合理推断；各缺口对现有误差的贡献仍需控制实验定量归因。

上一轮修复的独立东亚首年降水增量仅 0.52 mm，确实支持把排查重点从对流乘子转到大尺度环流与热力结构。但这个小响应本身不能证明任何一个遗漏机制就是唯一根因。

## 为什么东亚季风需要这些过程

季节日照、海陆不同的热响应、旋转和大尺度能量输送共同建立季节性环流。对东亚而言，亚洲大陆与西北太平洋之间的环流把湿气流引向陆地；还需要解释这些湿气流在哪里汇聚上升、雨带为何阶段性北移。

Chiang 等的地形控制实验发现，引入青藏高原后才出现其模型中的春雨、前梅雨、梅雨和盛夏等分阶段结构；论文将其联系到高原影响下的西风和下游北来气流，与季节增强的南来湿气流相互作用。这是一个有模型实验支持的机制框架，不表示所有高原作用都能归结为单一“热泵”或单一机械作用。[Chiang et al. 2020](https://atmos.uw.edu/~david/Chiang_etal_2020.pdf)。

另一个独立诊断指出，梅雨带上升运动与中层西风带来的暖平流有关；低层偏南风负责重要的水汽供应。中国梅雨锋通常具有明显湿度梯度，而低层温度梯度可以很弱。凝结加热又能加强上升运动。因此，“地表越热雨越多”和“有强冷暖温差才有锋面雨”都不足以覆盖梅雨。[Sampe & Xie 2010](https://journals.ametsoc.org/view/journals/clim/23/1/2009jcli3128.1.xml)。

## 实际执行路径

正式地球存档开启 `dynamicCirculation=true`，但没有选择 `circulationScheme`，也没有开启 `moistureScheme=transport`。上一轮 `shared-core` / `buoyancy` 则打开共享水汽并改散热比例，仍使用同一个 `AtmosphericCirculation` 类；`balanced` / `boundary` 只换该类的诊断压力闭合。

调用链为 `ThermalRuntime.sync` → `ThermalModel.advanceTo` → `AtmosphericCirculation.step` → `EnvironmentModel.step` → `WaterModel.step`。核查文件：

- [thermal-runtime.ts](../../../thermal-runtime.ts)，第 487–497 行：实时步进的耦合入口。
- [environment.ts](../../../environment.ts)，第 41 行：创建的实际环流对象；第 172–178 行：水汽与潜热耦合。

- [上一轮 profiles.json](../earth-east-asia-mechanisms-20261015/profiles.json)：年度对照的实际参数。

仓库中 C9/C10/C11 的分层动量、几何和压力波研究并未接入该实时路径。不能把“已有独立动力核实验”误当成“浏览器已经运行分层气候模式”。C9 自己说明尚无热力能量、长期气候或生产性能验收；C11 明确属于波动验证，不改变正式动力核。[C9 范围](../earth-rotating-sigma-20261014/CURRENT-STATE.md)、[C11 范围](../earth-pressure-waves-20261015/report.md)。

## 下一步应怎样验证

1. **先建立观测约束的环流诊断。** 在同一网格和月份上对照近地面风、SST、近地面温度；另用 850 hPa 水汽通量、500 hPa 高度及暖平流、200 hPa 西风急流位置定义未来分层模型的目标。当前单层风不能冒充任一指定等压面的风，青藏高原地下等压面必须屏蔽。
2. **做明确标记的离线强迫试验。** 用外部约束风场/热力场驱动独立水汽试验，比较雨季能否恢复，以区分大尺度强迫与成雨闭合。外部再分析通常自身已受观测约束；这种试验不是模型自主预测能力的证明。保持初态、时间步、陆地支持与多区域评估一致。
3. **若环流成为主要瓶颈，先验证分层热力与动量耦合。** 利用已有动力核研究，补一致的热量输送、静力/压力关系、上下层交换与地形作用，并用简化试验检验；不能把增加两层或加一个高原热源系数当作季风准确度已经解决。急流导引的天气尺度扰动可能参与平均梅雨带的维持，需要同时评估，不能全部留到极端事件阶段。
4. **验收雨季必须看空间与季节。** 同时检查华南—长江—华北/东北的雨带推进、春季和秋冬降水、多年漂移与外部区域。ENSO、MJO 和台风是后续变率/极端事件问题，不应在基本气候态尚未正确时，用它们替代对主环流结构的排查。

本轮结论支持调整研究路线，尚不支持指定某一个系数、宣称遗漏机制贡献了确定比例，或升级正式默认。
