# 独立代码审阅

审阅基线为 `be74609`，对象为 `codex/earth-ice-inventory` 工作树。审阅从初始化、相变、质量/焓账本、地表降尺度、回退、存档与现有 UI 控制流逐条追踪；没有把测试通过当作算法正确的充分证据。数据产品来源与视觉证据由其他独立核对流程负责。本审阅不修改实现，也不提交 Git。

## 第一轮必须修复项

1. **P1：观测冰配置使现有水循环/冰川开关和普通地形导入失效。** 原 `thermal-runtime.ts` 在 `iceInventory && (!waterEnabled || !environmentConfig.glaciers)` 时直接抛错；环境面板取消冰川或水面板取消水循环会 `invalidate()` 后走到该分支。`planet-controls.ts::restoreSettings` 导入普通地形时重设上述开关，但原实现没有清除观测配置。应让源配置在关闭水循环时休眠，让关闭冰川运动仍可保留观测冰库，并在普通地形导入/显式重置时清除地球冰配置。需要核对无冰川对象时 Inspect 仍从守恒库存计算冰厚。
2. **P2：降尺度后的海冰表面温度越过自己的融点。** 对首版 `after-day0.json` 严格恢复后扫描 96×49 地表，370 个海面样本有海冰却给出 `surfaceTemperatureK > 271.35 K`；52.5°N / −80.625° 的海冰覆盖为 1，表面温度为 +1.564°C。第 170 天同点覆盖约 0.0377，表面温度约 +15.70°C。`localReservoirTemperature` 将粗格异常叠加到局部参考温度，粗格相变边界不能自动保证插值结果的局部边界。应只修正实际冰面诊断的对应相界，不再夹限空气温度或改变守恒热层。
3. **P2：恢复时用未核对的显示初值重建动力学床高。** 首版存档单独把 `state.initialLandIce` 清零，严格恢复仍成功，水量/焓/反照率校验均通过，但冰川 `bedrockM` 最小值由 −553.557 m 变为 0，后续冰面坡度与流动也改变。应保存动力学床高并与当前 DEM 和初始冰库核对，禁止仅修改初值字段改变恢复后的动力学；同时保持没有外部厚度数据的旧档案默认床高兼容。
4. **P2：新冰架播种在有限海水耗尽时可产生负存库。** 8×4 网格全部 `land=.5`，`initialOceanDepthM=.0002`（海水 0.1 kg/m²），仅格 0 请求 201.6 kg/m² 的 `shelfLand`，首版 `seedShelves` 后海水为 −1.3877787807814457e−17，水量残差仍为 0。严格解码要求非负海水，因而这种生成状态不能保存恢复。扣除有限供水应有明确上限，并对耗尽库存补保存恢复回归。

以上均已发送给实施方并完成修复，最终核对见文末。首轮复现探针在未提交的 `build/earth-ice-inventory/review-probe.ts`，没有写入源实现。

## 已核对的机制

- Grounded、floating shelf 与 seasonal sea ice 分库；厚度以 917 kg/m³ 转为整格面积库存，播种从已有土壤/地表/海洋库存分配；浮冰架融水回海洋，grounded 融水进入地表径流。
- 新热层的陆地/海洋容量已各自包含陆海面积分数；冻结和融化只使用所属热层，水汽蒸发潜热从供水层取走，凝结/降雪潜热入空气层。总焓包含三个 sensible reservoirs、蒸汽潜热与各类冰库存的 fusion 项。
- Ocean transport 使用海洋温度与容量，Land ice flow 使用床高加当前库存厚度；不会把 ETOPO 冰面 DEM 再加一遍初始冰厚。
- 新配置为显式开关，默认程序星球保留原行为；旧存档缺少浮冰架字段按零库处理，新分热层档案要求完整温度字段。
- 回退使用 thermal/water/vegetation/circulation checkpoint；新热温度与冰架库存随各自 checkpoint 保存。

## 数值兼容修复审阅

上一轮已经记录的 Browser→Node 存档反照率约 5.55e−17 差异，来源是浮点重算而非本次新增质量/能量回归。最终实现把反照率重算比较限制为 `8 * Number.EPSILON` 的绝对容差（约 1.78e−15），没有跳过验证。独立复审确认 1.11e−16 的变化可恢复，0.001 的实质变化仍拒绝；质量和焓账本继续独立校验。这是对已知数值兼容问题的有测试修复。

## 需要如实保留的模型限制

首版连续第 170 天统计中，85°N 海冰约 3.713 m，65°S 约 7.074 m，南极混合粗格可达 11.196 m。当前海洋相变把混合层冷量直接转为海冰，没有海冰传热阻力、漂移或真实盐度模型；这次不能据此宣称季节海冰已校准。85°S 初始粗格空气温度约 +1.56°C，而局部参考空气约 −59.64°C，说明极区粗格混合与局部参考降尺度仍有明显差异。报告应分别列物理格和局部显示统计，且明确连续积分与季节参考的区别。

库存演化保留导入的冰面 DEM 基准。冰川质量流动/融化不实时重绘地形顶面；正高程掩膜上的浮冰架完全消失时也不自动改变海岸线。这保证本次没有重复叠加冰厚或伪造地形，但不构成动态冰面几何或冰架退缩模拟。

局部显示种子/温度元数据目前只做尺寸和范围核对，单独改变它们可以改变显示而不改变物理账本。这不导致质量/焓丢失，但其校验强度不能描述成每个显示字段都已与源产品逐值验证。

## 最终复审结论

**通过；在本次代码审阅范围内没有剩余待修复项。** 第一轮 4 项缺陷及复审发现的诊断兼容缺陷均已核对修复。

- 有限冰架供水扣除只把乘法舍入导致的负尾差限到零；上述 0.1 kg/m² 供水复现保持非负，水量残差小于 1e−10 mm，没有增加实质供水。
- 关闭水循环保留休眠源配置；关闭冰川运动保留真实冰库但不产生 `GlacierModel`，Inspect 冰厚仍直接从质量库存计算。普通地形导入和 Painting Reset 清除地球冰配置，普通气候重置/地形编辑继续保留配置。完整模拟恢复由候选 runtime 接管自己的配置。
- `GlacierCheckpoint.bedrockM` 为可选字段：旧程序星球档案没有它时继续采用原始 `water.heightM`；观测厚度场景保存并要求床高与 DEM−初始库存厚度一致。缺失床高、单改床高、单改初始 grounded 库存均拒绝，旧地球第 0 天档案已实际恢复。
- 有冰的局部 `surfaceTemperatureK` 使用对应融点上限，`localTemperatureK` 的空气诊断不夹限。关闭水循环时，无环境分支也返回完整的表面温度和零冰架字段，避免 Inspect 对缺失字段调用 `toFixed()`。
- Inspect 分别标示空气、表面温度与冰架厚度；比较图海面 RGB 使用 `max(seaIceFraction, shelfIceFraction)`。季节海冰库存/范围指标仍只计 sea ice，浮冰架不混入季节指标。
