# 物理与视觉证据复核

审查日期：2026-10-10。复核范围为真实冰厚来源、海岸离散处理、冰面与床高相容、库存守恒解释以及同镜头截图；不修改核心代码。本报告不把数值守恒或可见白色当成已完成地球气候校准。

**最终结论：通过；在本次数据、库存账本、床高相容和视觉回归审查范围内，没有新增阻塞项。** 第 0/170/350 天物理快照和五视角共 30 张前后截图均已核对。季节海冰偏大、冰架全年没有净消融及粗格诊断条带仍是明确限制，本结论不扩展为真实地球季节气候验收。

## 来源与分类

已复读 [DATA-SOURCES.md](DATA-SOURCES.md)、源采样代码及 `ice-source.json`，与 [GFZ 正式发布](https://doi.org/10.5880/GFZ.1.2.2024.002)、[作者 readme](https://datapub.gfz-potsdam.de/download/10.5880.GFZ.1.2.2024.002-Veebui/2024-002_Abrykosov-et-al_readme_GDEMM2024.txt)、[论文表 1](https://www.nature.com/articles/s41597-024-03920-x/tables/1)的既有来源核对一致：GDEMM2024 的 ICE 是继承 BedMachine Greenland v5 / Antarctica v3 的独立厚度。LTM=3/5 是大陆冰库存类别；5 表示冰下湖上方冰层，不声称与湖底岩石直接接触。LTM=4 进入独立冰架库存；该数据没有季节海冰。许可、单位、像元注册、nodata 和使用字节范围校验均有记录。

罗斯控制点 `SUR−BED=662 m`，ICE 仅 334.5 m；Vostok 的相应差值约比 ICE 多 574.5 m。这些水腔不能作为冰注入。源 GDEMM SUR/BED 使用 EIGEN-6C4 geoid，保留的 NOAA ETOPO 冰面使用 EGM2008；574 个冰点的表面差 RMS=36.53 m、范围 −326.29 至 +408.20 m。该差不能解读为一种固定垂直偏移。选择独立 ICE、保存 BED 作诊断、保留 authored surface 的策略符合这些语义。

采样并非完整原始冰盖清单：1 角分源网格降为 96×49 的点种子，最近邻分类、同类插值厚度，窄冰缘和小岛会概化。533 个大陆冰点和 41 个冰架点包含极点行重复坐标，不能转换成冰面积。高原控制点输入零冰仅说明这次全球极地产品未注入高原冰；不能声称现实山地冰川不存在。

## 海岸与面积复核

独立恢复最终第 0 天存档，并逐点检查 [coastline-policy-review.json](coastline-policy-review.json)。它绑定的完整存档 SHA256 为 `1fe24db85125e815ed576059b1c387c505a01773f148ef7a766ec9616b151ac3`。

- **6 个源 grounded 点对应 `localLand=0`**：保留其来源记录，聚合时局部陆地权重为零，局部可见大陆冰厚严格为 0。没有为了接纳这些点而改 DEM 或扩大陆地面积。不能据此声称完整原始体积全部导入。
- **12 个源 shelf 点对应正的部分陆地比例**：仍作为 shelf，分别按现有陆地/海面面积分配两个冰架热层库存；两份 conditional shelf 种子均为正，最终局部加权厚度等于源厚。没有变为 grounded 或 seasonal sea ice。这里的陆地份额是既有正高程掩膜对应的热交换面，不代表该冰架在地质意义上接地。
- 本地 `localLand`、`localHeight` 在前后初始存档逐值相同。冰分类点不能覆盖整格海陆类型；面积权重聚合与真实冰缘点图保持不同含义。

额外量化只给出**代表格的整格地理面积上限**：采用场景半径 6,371,008.4 m、经向宽 3.75°、纬向中心 ±1.875° 的球面四边形，`A=R²Δλ(sin φN−sin φS)`。6 个 grounded 冲突点对应格合计 213,556.52 km²；12 个 shelf 混合点对应格合计 505,435.91 km²。它们不是源掩膜实际冰面积、已丢冰面积、岸线误差估计或真实冰量上限；一个点的类别不能确定整格覆盖。逐点面积与恢复结果保存在上述 JSON。

## 冰面、床高及质量与焓

第 0 天物理床高按 `authored DEM − initial grounded inventory/(917×landFraction)` 建立。独立检查全部物理格，最大相容误差为 0 m；模型没有再次把初始冰厚加到 ETOPO 冰面。产品 BED 仍独立保留，用于来源诊断。Vostok 的兼容参考位于冰底/湖水顶面，不应命名为实测湖底基岩；冰架对应差值也是冰底面参考。

这是一种保留已编著表面且避免重复厚度的相容策略，适用于当前模型；它不是整合两套 geoid 的地质床高重建。当前冰流/融化改变库存与诊断，没有实时重绘地形顶面或海岸线，也没有真实冰架流动、崩解和海水腔动力学。正高程掩膜上的冰架即使融尽也不会自动成为海洋岸线。

第 0 天大陆冰为 49,438.5762 mm 全球水当量，冰架为 1,040.6982 mm，来自已有水库分配；海洋水库为 688,718.8822 mm，总水仍为 739,407.31649 mm。**每个物理格的库存单位是整格面积 kg/m²**，厚度是条件陆地/海面上的米，不能重复乘面积比例。96×49 显示下采样的区域体积是估计，正式守恒账本使用 48×24 等面积物理格。例如南极冰架物理体积 578,870.87 km³，而显示估计 634,212.76 km³；二者不能混用来断言模型质量偏差。

第 0 天的初始焓是在分配观测冰并建立各热层相容相态后记录的。基线与改版初始焓不同，不能声称该初始化维持了旧场景的同一能量。连续积分所检验的是 `current enthalpy − new initial enthalpy − accumulated radiation`，并包括三个 sensible reservoirs、蒸汽潜热和 snow/grounded/shelf/seasonal sea ice 的 fusion 项。

## 连续积分与视觉对照

已逐张查看第 0 天南极、北极、格陵兰、南北美洲和青藏/喜马拉雅的五组前后图。镜头、画布、海岸与地形一致；南极内陆与格陵兰显示为有厚度库存对应的冰面，海冰保持独立。低纬海洋仍有原有蓝色、海底起伏和光照纹理，没有明显新亮斑、黑洞、接缝或岸线漂移。极区大范围亮白与光晕在基线已有，不能称为本次新光照缺陷，也不能作为真实冰界验证。

第 170 天基线格陵兰已完全无大陆冰/雪，改版仍有约 264.43 万 km³ 的区域大陆冰；南极仍有约 2,459.10 万 km³。局部格陵兰内部厚度从 3,087.5000 m 到 3,087.3516 m；南极内部从 2,526 m 到 2,526.000011 m。这支持观测库存实际演化、数千米冰盖没有被一季节气温阈值抹去。区域格陵兰矩形可能包含附近陆地，覆盖率不是遥感范围产品。

已查看第 170 天南极、北极、格陵兰、南北美洲、青藏及温度/径流切换图。格陵兰冰盖在基线图中呈裸地，改版仍可见冰面；Inspect 的局部/物理格厚度、空气与表面温度和快照一致。青藏夏季图恢复裸露高原，没有导入虚假的千米冰层。低纬海岸、海面蓝色与光照纹理延续。径流诊断图的北极有放射星形条带，不能称为真实河网或新增冰融水通道；没有同层基线图，未据此认定本轮新增回归。

第 350 天局部南极内部为 2,525.9442 m，格陵兰为 3,087.3317 m；区域大陆冰分别为约 2,459.0802 万 / 264.4276 万 km³。冰架物理体积在三个时点均为 578,870.8716 km³；该积分未发生净冰架消融，不能据此宣称再现了真实冰架季节消融、崩解或动态退缩。

季节海冰仍存在明显问题：第 170 天北极物理范围约 1,985.69 万 km²，南大洋（50°S 以南）约 4,850.98 万 km²；85°N 点约 3.713 m、65°S 点约 7.074 m。第 350 天北极仍约 2,061.34 万 km²，南大洋约 4,790.13 万 km²，85°N 点已增厚至 12.573 m。图中的大范围亮白海冰与这些不理想统计相符，其范围与厚度不能描述成逼真的季节校准。浮冰架没有计入这两个季节指标；本轮通过的是分库、质量/焓账本和大陆冰存续，不是海冰漂移、传热阻力或盐度模型的完成。

第 350 天南极、北极、格陵兰、南北美洲和青藏的前后截图已全部核对。基线格陵兰仍为裸地，改版保持有厚度库存的冰面；南极保持冰面，青藏的白色仅对应季节雪而没有来源厚冰。低纬海岸和海面光照纹理没有明显回归。极区海冰仍形成宽亮环和粗格边缘，不能作为精确遥感冰缘或季节真实性通过的证据。

还核对了 [after-playback.jpg](after-playback.jpg)、[environment-playback.jpg](environment-playback.jpg) 与 [playback-metrics.txt](playback-metrics.txt)：浏览器从约第 170 天实际继续播放到第 342.5025 天并暂停，画面保留格陵兰冰面；水/焓诊断约 −5.22e−8 mm / −2.64e−4 J/m²。该浏览器播放时点与固定步长第 350 天证据分别记录。高倍速播放出现明显交互延迟，不能把“能暂停/账本正常”表述成该倍速始终流畅。
