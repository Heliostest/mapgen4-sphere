# 第4部分实施约束与验收计划

用户已给出完整实施范围及自动审阅、提交、合并、推送授权，按此范围连续执行。

1. 复现旧参考网络对全部内陆洼地接海、硬编码显示参数；保留第0天三个固定镜头截图。
2. 参考网络复用真实水流的邻接边与鞍部。可选观测内流集水区标识提供内部终点；在各连通区内建立无环汇流树。普通程序地形继续使用海洋出口，局部凹坑不会因此变成永久内流区。观测标识不能成为物理水墙。
3. 真实有限水库继续按自身水位、边缘鞍部、接收水位决定出流，雨/融雪/蒸发均与权威粗格账本协调。参考年径流不进入水库；真实溢流以真实瞬时流量独立绘制，不把年参考流量当成溢流。
4. 新融合显示参数置于 render，提供最小流量 m³/s、宽度系数与三角形边长宽度上限；只重绘，不生成气候或雕刻DEM。缺失字段的旧档使用原显示数值，正式场景采用较克制值。地形内流标识可选保存且严格校验，Reset清除；新网络对象使派生缓存失效。
5. 先写失败回归，覆盖观测盆地终止、鞍部拓扑、平台/嵌套无环、显示参数有效而账本不变、旧存档兼容；复核已有蓄水/干涸/溢流测试并增加独立预算证据。
6. 固定同状态截图、真实播放暂停与水流诊断、地球案例拓扑核对；独立代码与物理视觉审阅，修复后执行完整测试、typecheck、build、严格场景verify、diff check。正常合并main并推送origin，核对本地与远端一致。

边界：不启用实验共享水汽、不改原DEM、不注入未知湖水位、不加密气候网格。观测盆地与约50km地形网格的匹配、低于海平面陆地+1m约束和缺少初始湖水位均在报告披露。
