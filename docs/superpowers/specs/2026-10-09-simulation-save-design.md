# Simulation save and resume

Continue the authorized phased development on `codex/coupled-environment`, based on c9c26bf. Stage 1 makes a saved world resumable at the same visible instant. Later stages are dynamic rivers/lakes/wetlands, glaciers, circulation, and clouds, in that order; each has its own acceptance and local commit.

Use a versioned `mapgen4-sphere-simulation` JSON envelope containing the existing terrain document, runtime settings and state, clock speed/display layer, and comparison baseline/history. Keep explicit terrain-only download/import for version-1 legacy files. Snapshot all state needed for the next step: temperatures, radiation and heat-exchange sums and compensation, absorbed flux, water stores/fluxes/winds, snow/ice, vegetation means/weights, initial budget values and geographic reference fields. GPU textures and diagnostic fields may be rebuilt without generating climate or advancing time. Ephemeral erosion preview and undo stacks remain excluded and are described in the UI.

The loader validates versions, identity, dimensions, finite numbers, parameter ranges, state relationships and a 32 MiB UTF-8 limit. It creates a candidate runtime and rebuilds candidate terrain in a separate worker before modifying live state. Changes made during the asynchronous preparation cancel the load. Commit the complete prepared world synchronously, paused; malformed files or failed preparation preserve the existing world. Geographic surface samples retain the 96×49 grid including both poles.

Acceptance: exact JSON snapshot roundtrip; independent ownership; uninterrupted versus saved/reloaded continuation agrees in state and budgets; enabled/disabled/thermal-only configurations; visible rollback; corrupt/oversized/version/mesh cases; real browser download, reload, resume, parameter/baseline recovery, failed-load preservation, and unchanged rendered surface. Run all Node tests, typecheck, build and relevant browser regressions, inspect screenshots, document results, then commit locally. No push or merge.
