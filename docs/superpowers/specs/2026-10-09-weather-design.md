# Moisture-driven cloud and precipitation display

**Product scope update:** the subsequently authorized cloud-only display supersedes rain/snow glyphs, wind-aligned marks and decorative animation in this original design. Total precipitation and recorded land snowfall remain physical diagnostics, with initial estimates and unavailable legacy phase explicitly labelled. Current scope and limits: [weather.md](../../weather.md); current acceptance and retained stability failure: [stage-five recheck](../../weather-stage5-recheck.md). The paragraphs below preserve the initial release design history.

Final authorized stage. Add an optional display-only Cloud & precipitation overlay on Natural surface. Its scalar cloud-opacity proxy comes from the existing column water divided by the same temperature-dependent moisture capacity used by condensation. Rain/snow glyph intensity comes only from actual last-step precipitation; zero-age generated precipitation estimates are not shown as evolved rain. Wind-aligned rain strokes use the same saved winds that transport moisture. Cloud patterns change because the conserved water fields evolve, with no independent animation clock or random weather generator.

Display is an illustrative surface overlay, not atmospheric cloud liquid, vertical cloud geometry or a forecast. Smooth geographic interpolation shares one scalar value at each pole and wraps longitude. Cloud opacity is bounded; rain/snow are visibly distinct. No extra water reservoir, radiative feedback or mutation. Disabling returns exact underlying pixels. Original and diagnostic layers remain readable. Inspect shows source values and the legend identifies the proxy and units.

Persist only the view switch in complete files; derive pixels deterministically from saved physical fields. Old files default false. Tests must cover dry/condensing/freezing source fields, read-only behavior, poles, exact regenerated texture, physical moisture movement, valid/legacy/invalid view options. Browser/GPU acceptance verifies actual overlay pixels, dry/off restoration, wind orientation, snow versus rain, pause, evolution, save/resume, Original, mobile and budgets. Independent review and a local commit conclude this phase.
