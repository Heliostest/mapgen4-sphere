# ExoPlaSim 最小对接实验

用户已选择运行原型：现有地形 → ExoPlaSim → 气温、降水、风场导回同一球体，与当前模型比较。本轮在现有检出的 `codex/exoplasim-bridge` 分支实施；原生工作树工具未响应，未创建手工工作树。

范围：独立实验页和离线复跑脚本；固定上游 daface8，CPU/WASM FP64、T21、10层。默认读取现有完整地球存档，也接受其他完整模拟存档。运行第一个完整年，明确标记首年瞬变，不宣称平衡气候。采用上游逐物理步发布并按实际步长累计，输出12个月；基线沿用原模型物理配置与完整地形，从对应一月季节重新初始化。两者初态与物理闭合不同，保留配置以解释比较边界。

- [x] 先用失败测试固定经度/纬度方向、Gaussian面积守恒重映射、降水单位、非法数据拒绝和统一配色。
- [x] 实现输入导出、独立WASM构建和逐步月平均；并实际跑满一年。
- [x] 实现现有模型独立年度基线，按秒积分、同月输出；记录地形和配置哈希。
- [x] 给现有球体增加实验专用只读显示入口，实验页按模型、月份、字段切换并显示统计及字段含义。
- [x] 运行测试、类型检查、构建和真实浏览器检查，保留结果、截图与复跑说明。

不修改正式地球存档和物理公式，不将参考降水注入现有水库。地形物理高程不含视觉夸张；地形栅格化是近似，报告陆地比例。显示使用48×24等面积网格并保留原始GCM网格；风的最低sigma层与当前单层风分别标记。

验证：原有290项与新增7项数值/输入测试全部通过；类型检查、构建和6组浏览器检查通过。独立审查发现的普通生成地形河谷保高错误已修复，回归验证旧行为失败/修正后通过。默认地球重新导出输入与年度运行输入SHA-256完全一致。实际结果和复跑入口见 `experiments/exoplasim/README.md`、`REPORT.md`、`REVIEW.md`。
