# 地点探针：现有对照原型增量

用户请求：在球体上选具体地点，查看当前情况及全年情况，尤其月降水分布。当前结果仅有12个月均值，因此“当前”明确显示为所选月份月平均，不提供不存在的逐时天气。

沿用现有页、同一球体与12个月数值；点击与拖动分开。球面标记使用地理方向着色，旋转到背面自然隐藏。显示选点经纬度、物理高程、所属等面积气候格及其中心，避免把粗气候格均值当成精细地形点预测。

- [x] 数值测试先固定经纬取格、日期变更线/两极、实际采样秒数转月降水毫米、年量和时间加权年温。
- [x] 增加只读拾取/地理标记接口，不改变物理库存。
- [x] 增加地点面板：选月双模型读数、12月双模型降水柱图/气温折线、年降水/年温、数值表和CSV。
- [x] 点击月份同步全局月份；切模型/图层/镜头保留地理选点；清除探针；桌面及移动端验证。

界面沿用灰白背景、深蓝文字；原模型为灰蓝，Exo为青绿，探针标记为琥珀。字体沿用系统中文，数值使用等宽数字。图表是重点，周边保持安静。格点与采样覆盖说明只在地点信息中出现，原生冷启动限制继续保留。

验证：`npm test` 共301项通过；`npm run build`、`npm run typecheck`、`git diff --check`通过。真实Chrome探针9组交互回归、既有对照7组回归通过，无页面错误，全部操作前后物理runtime SHA-256完全一致。证据见 `experiments/exoplasim/evidence/probe-browser-report.json` 及 `probe-desktop.png`、`probe-annual.png`、`probe-mobile.png`。

独立审查发现旧存档非零镜头倾角会使部分南方坐标无法居中，并误取中心海拔；先加入真实浏览器失败复现，再修正定位时的镜头倾角，回归通过。当前地球存档原倾角为0，物理数据未变。
