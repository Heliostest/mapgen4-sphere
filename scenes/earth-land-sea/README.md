# 地球真实地形预览

启动仓库的本地服务器后，打开 `/scenes/earth-land-sea/index.html`。入口使用现有编辑器和完整模拟导入流程，自动恢复第 0 天的暂停场景。默认「地球地表」同时显示真实地形、冰雪、植被与连续河网；无需 Play。顶部选择青藏高原、安第斯山、各半球和两极；右侧「显示图层」是唯一的图层入口，可查看气温、降水、昼夜、风场和水流等诊断。拖动旋转，滚轮缩放，Play 继续演化。

右侧中文控制台按「显示与播放」「行星与气候」「地形编辑」「画面设置」「保存与恢复」折叠分组，默认只展开常用操作。画笔、图例、季节和高级参数收在对应子组。`sidebar.js` 重用原控件与事件，`sidebar-zh.js` 翻译呈现文字、说明及动态状态；不改输入值、控件标识或存档格式。

`sidebar-zh.jpg` 是整理后的浏览器截图。浏览器检查覆盖分组展开/收起、气温与地表切换、播放/暂停时的中文读数、画笔模式、存档入口及环境对比；390 像素窄屏下改为上下布局，无横向溢出。

地球场景使用 `mesh=high`：215,348 个三角形（原版 53,834 的约 4 倍），地形采样间距约减半。默认高度夸张从约 106 倍降为 12 倍，顶部可切换 1 倍真实高度或 40 倍强调显示；这只改变显示高度，不改变物理海拔。常规编辑器保留原网格及旧存档兼容性。独立导入此高精度存档时，请使用 `/embed.html?mode=editor&mesh=high`。

- `earth-simulation.json`：真实高程地形和已生成的温度、水循环、冰雪、植被、海流状态。默认融合地表视图（`surface`），云层关闭。
- `earth-terrain.json`：同一地形的独立导入文件；导入后需 Generate climate now。
- `source.json`：Natural Earth 海岸线来源。
- `elevation-source.json`：NOAA 高程来源、单位、分辨率、校验和、采样方法及十个高程对照点。
- `elevation-samples.json`：215,348 个实际网格三角形的米制高度，供离线复现。
- `validation.json`：完整存档解码、网格高度、河流生成保高、气候高度一致性、11 个陆海定位点和两极检查结果。
- `high-relief-himalaya.jpg`、`high-relief-true-scale.jpg`：高精度地形的 12 倍和 1 倍高度截图；`high-natural-playback.jpg` 是实际播放到约 0.53 天后的自然地表。
- `unified-surface-asia.jpg`、`unified-surface-americas.jpg`：融合后的地球地表，第 0 天暂停，地形、冰雪、植被与河网同屏。
- `unified-surface-playback.jpg`、`unified-visual-validation.json`：浏览器实际播放到约 3.40 天后暂停的截图，以及受控湖泊 GPU 测试结果和浏览器错误记录。
- `performance.json`：此场景的本机 CPU 计时和水量守恒检查。`benchmark.ts` 可复测；计时不代表浏览器帧率。
- 未带 `high-` 前缀的地形和自然地表截图保留为上一版低精度预览的历史记录。
- `before-height.jpg` 和上一版六张地区截图保留为程序地形阶段的历史记录。

高程来自 [NOAA ETOPO 2022](https://www.ncei.noaa.gov/products/etopo-global-relief-model) 的冰面版本：南极、格陵兰采用冰盖表面高度，同时包含陆地地形和海底水深。经 [NOAA ERDDAP](https://coastwatch.pfeg.noaa.gov/erddap/griddap/ETOPO_2022_v1_15s.html) 按 24 步长提取原始 15 角秒数据，得到 0.1° 栅格，再按实际球面三角形位置做双线性采样。高程单位是米，相对于 EGM2008。

2026-10-10 拟真审查完成第 24 天七个地区的同状态显示对照，并以正常浏览器时钟连续播放至第 169.79 天、9,351 个物理步。仅采用显示光照 `overhead: 30 → 60`，减弱坡面黑色阴影；12× 起伏与全部物理配置保留。热输送、辐射率、海洋/陆地热容量候选均因地区退化而未采用。亚马孙/刚果偏干、极区海冰季节范围失真及冰盖初始化不足仍需机制改善。见 [完整审查、实验与截图](../../docs/evidence/earth-realism-20261010/REPORT.md)。

`scene-config.json` 是有效显示配置，`make-world.ts` 在地形生成时读取。运行 `node scenes/earth-land-sea/apply-render-config.mjs` 可将配置应用到已有地形和模拟存档，保持物理状态；`audit-realism.ts` 生成可加载的参数候选与 24 天实测统计。正式存档仍在第 0 天暂停。

2026-10-10 海水/海冰光照机制修正：海面使用基础球面的局部法线，描边高度使用实际可见表面高度，消除海床坡面阴影和脊线在水面、海冰上的透印。陆地坡面光照、真实海底 DEM 与水深配色保留。四地区第 0 天同状态对照、实际播放及独立审阅见 [截图与验证报告](../../docs/evidence/earth-seaice-lighting-20261010/REPORT.md)。

陆地轮廓继续采用 [Natural Earth 1:50m Land](https://www.naturalearthdata.com/downloads/50m-physical-vectors/50m-land/) 4.1.0，公共领域许可。这次在实际网格上以 0.1° 纬度扫描线判定陆海，不受原有 128 列画笔网格限制；北极为海洋、南极为陆地。由于应用以高度正负判断陆海，低于海面的陆地及两个来源在海岸的少数分歧采用 ±1 米边界值，调整数量保存在来源记录中。

采样高度通过现有持久地形层替换程序起伏，关闭装饰性山脉褶皱。来源注记随地形与模拟存档保存；生成艺术河流时保留导入高度，后续显式应用侵蚀仍可改变地形。画笔和地形参数仍可编辑，在导入基准上叠加变化；Reset 清除导入层。

画面垂直起伏有夸张，实际物理高度仍以米计。当前球面网格会概化小岛、狭窄山峰和海沟，不能还原珠峰精确峰高。气候、冰雪、植被及河流仍是简化模型，不是地球观测数据；海流并未升级为使用真实水深的三维海洋模型。

河流没有手绘或套用地球河道矢量。融合地表使用 [Priority-Flood 填洼](https://richdem.readthedocs.io/en/latest/depression_filling.html)生成参考排水树，将各三角形上的估计径流按面积向下游汇集，所以第 0 天就能看到连续的支流与干流。参考年径流采用年降水的 35% 这一示意系数，再根据当前土壤湿润程度、液态降水和融雪更新河宽。冰雪覆盖的河段不画蓝线，其上游贡献仍可传至下游。

参考河网仅用于显示，不写入真实高程或水量账本，也不会凭空注水或立即排空真实洼地。实际湖岸、地表积水、坡向流量及溢流仍由守恒蓄水模型计算，可在 Inspect 和水流诊断中检查。填洼参考河道可能穿过现实中的闭流盆地，河宽也为可读性作了夸张；它不是实测地球河网或瞬时流量预报。气候计算保持原来的 1,152 个单元以控制运行开销。

第0/170/350天实际连续积分、同镜头截图、严格保存恢复、浏览器播放/暂停、守恒账本与独立审阅见 [完整报告](../../docs/evidence/earth-ice-inventory-20261010/REPORT.md)，重新生成方法见 [复现说明](../../docs/evidence/earth-ice-inventory-20261010/REPRODUCE.md)。`ice-samples.json` 是离线厚度/掩膜样本，`ice-source.json` 保存版本、数据许可、坐标基准、缺测处理和实际源字节校验；`sample-ice.py` 可重新采样，`rebuild-ice.ts` 用固定旧场景重建库存。

## 数据生成

从仓库根目录运行。Python 需要 NumPy；Node 使用仓库已有的 esbuild。

1. 用 esbuild 将 `scenes/earth-land-sea/make-world.ts` 打包成 Node ESM，运行并传入 `--coordinates`，输出当前网格坐标。
2. `python scenes/earth-land-sea/sample-elevation.py` 下载/校验 NOAA 与 Natural Earth 数据并采样。约 26 MB 的原始高程响应缓存于 `build/earth-relief/`，不随场景存档传输。
3. 再运行打包后的 `make-world`，不加参数，写出 `earth-terrain.json`。已有的 `elevation-samples.json` 可用于完全离线重建。
4. 在 `/embed.html?mode=editor&mesh=high` 导入地形，勾选环境面板的环流、冰川和地形水流，点击 Generate climate now，保持第 0 天暂停，下载完整模拟为 `earth-simulation.json`。不需要 Play。入口默认视图可由存档中的 `view.layer` 设置。
5. 用 esbuild 将 `scenes/earth-land-sea/verify.ts` 打包成 Node ESM，再运行，验证实际生成网格和完整存档。

融合版本验证：161 项测试通过，类型检查和构建通过。新增测试覆盖暂停态河网、上游面积汇流、显示不改水量、存档重建一致、干旱消退、融雪恢复和冰盖遮挡。约 10.1 MB 的完整模拟在真实浏览器中重新载入，确认默认融合视图及图层往返，实际播放到 3.399817 天后暂停，浏览器未记录到错误或警告。受控湖泊 GPU 测试通过：干地与排干状态无水面，增加蓄水量时湖面扩大。场景验证器同时检查默认 `surface` 图层和原有真实高程数据。

采样网格点：安第斯高原约 3,654 米、亚马孙平原约 44 米、恒河平原约 107 米、马里亚纳海沟约 -9,351 米。网格到存档的最大数值传递误差小于 0.001 米；这是序列化误差，不代表原始数据或球面网格的空间精度。

性能探针在本机 Node 中预热两步后测量五步：单步环境计算中位数约 21 ms，融合河流与湖岸几何更新约 69 ms，水量残差约 2.33e-9 mm。场景默认每秒推进一小时；极高倍速和弱显卡仍可能降低交互流畅度。
